## 启动与预览

需 Node.js 22.18+（制作验证使用24.18）。从游戏仓库根目录执行（README位于 docs 中）：

```sh
npm ci
npm run dev -- --port 5173 --strictPort
```

已安装依赖时可跳过 `npm ci`。打开 http://localhost:5173/ ，运行服务的终端需保持开启；终端关闭后地址不可用。若5173已被本项目服务占用，直接使用现有地址。

```sh
npm test
npm run build
npm run preview -- --port 4173 --strictPort
```

构建预览 http://localhost:4173/ 。`dist/` 是可分发的完整静态网页；无需原始班史资料或运行时网络服务。可上传整个 `dist` 到静态站点根目录或子目录，资源路径为相对路径。不应直接双击 index.html，以HTTP服务打开。

旧分发包已移至仓库根目录 `.local-archive/game-cleanup-20261005/releases/`，不上传 GitHub，也不代表当前版本。最新分发使用 `npm run build` 生成的 `dist`；可在 `game` 内执行 `node scripts/serve-dist.mjs` 预览。当前未公开部署外网。

## Vercel 自动部署

`game` 已建立独立 Git 仓库，本目录的 `vercel.json` 已配置安装、构建和输出目录。通过 GitHub 等 Git 平台导入这个独立仓库时，Vercel 的 **Root Directory 保持默认仓库根目录**，不要填写 `game`。配置会执行 `npm ci`、`npm run build`，发布 `dist`，Framework Preset 为 Vite。Node.js 使用 Vercel 当前默认的24.x，无需环境变量。

首次需要在 Vercel 中关联仓库并点击 Deploy；之后推送生产分支会自动部署，其他分支生成预览。配置文件本身不负责创建账号、关联仓库或上传本地未提交文件。此前按旧说明部署整个 ClassHistory 仓库的项目不受影响；新独立仓库使用本目录的配置。

提交最新 `src`、`public`、依赖清单和配置，特别是新增个人立绘；不提交 `node_modules`、`dist`、原始照片及 `.aws` 等无关配置。构建直接使用已生成剧情数据，不运行素材生成器，不需要原始PDF或上级转写文件。当前运行图片约167MiB，推荐 Git 导入构建，避免 Hobby CLI 源码上传的100MB限制。

部署后访问站点首页即可游玩，`/#class` 为全班人物页；现有哈希路由无需重写规则。localhost 与线上域名的存档独立，迁移请在本地导出、线上导入。

官方依据：[vercel.json 配置](https://vercel.com/docs/project-configuration/vercel-json)、[Git 部署](https://vercel.com/docs/git)、[上传限制](https://vercel.com/docs/limits#static-file-uploads)。
