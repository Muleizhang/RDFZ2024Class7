# 游玩与部署

本文件说明操作、存档和发布方式。游戏介绍见[README](../README.md)，维护入口见[开发与维护](开发与维护.md)。以下命令均在这个独立游戏仓库的根目录执行。

## 操作与阅读设置

封面按当前自动存档显示所在日期、章节、日题与场景背景；无可用存档时显示开场。按钮从上到下为“继续上次的记录”“翻开第一页”“全解锁作弊码”“全班人物”；没有存档时继续按钮禁用。

- 点击对白、按空格或 Enter：第一次补全正在逐字出现的文字，第二次推进。数字键按屏幕编号选择，最多支持五项。
- 设置中的文字速度为10—100毫秒／字；“即时显示全文”与“减少过场动画”是两个独立开关。开启减少动画仍可逐字阅读。
- 自动播放遇到选择停留；已读快进只跳过读过的内容。长选项在窄屏内滚动显示。
- 失败只显示一句结语。点击“重新选择”、按空格或 Enter 返回刚才的选择，保留已读和失败收藏。
- 手帐提供回看、日期重访、人物、存档、结语收藏、出处及设置。手机可展开左上角课表／行程。
- 首页“全班人物”打开独立人物页，也可访问 `/#class`。姓名、别称和简介可以搜索；打开人物页不推进剧情。
- 首页“全解锁作弊码”是原句填空，逐字精确匹配。正确后解锁日期、已读和失败收藏，不替玩家制造逐句游玩记录，也不跳走当前剧情。验证保存摘要而非明文答案，但原话仍在剧情中；它是便捷入口，不是访问权限保护。

## 存档与迁移

推进时自动保存，长篇中途可以退出；下次使用“继续上次的记录”。另有手动存档、JSON文件导出／导入和粘贴存档文本恢复。导入入口执行相同校验。旧样章及旧全篇存档经节点迁移继续读取；已读与失败收藏保留，改写或撤下的节点按兼容表处理。

存档在当前浏览器的本地存储中。localhost、Vercel、GitHub Pages、不同端口和不同浏览器的存档互不共用；跨站点或设备使用导出再导入。清除网站数据前先导出。

作弊码校验使用 Web Crypto，需要 HTTPS 或 localhost。普通 HTTP 局域网地址若不支持该接口，游戏会显示提示。

## 本地运行与构建

使用 Node.js 24；现有测试依赖 Node 原生 TypeScript 去类型支持。此项目不需要 Python、conda 或全局配置更改。

```sh
npm ci
npm run dev -- --port 5173 --strictPort
```

打开 http://localhost:5173/ ，保留运行服务的终端。若该端口已由本项目占用，可直接访问现有服务；终端关闭后地址将不可用。

```sh
npm test
npm run build
npm run preview -- --port 4173 --strictPort
```

构建预览在 http://localhost:4173/ 。`dist/` 包含可分发的静态网页与本地图片，不需要原始班史或在线剧情服务。上传整个目录，不能只上传 index.html。资源使用相对路径，支持站点根目录与子路径。通过 HTTP 服务打开，不直接双击网页文件；也可用 `node scripts/serve-dist.mjs` 预览构建。

## Vercel

本仓库已有[vercel.json](../vercel.json)，使用 Vite、`npm ci`、`npm run build`，输出 `dist`。在 Vercel 导入 GitHub 仓库 `Muleizhang/RDFZ2024Class7`，Root Directory 保持仓库根目录，不填 `game`。首次关联后部署；后续生产分支推送由关联的 Git 部署处理。

构建直接使用已生成的 `src/data`，不运行剧情生成器，不需要上级目录的PDF、转写文件或环境变量。Vercel域名以已关联项目的 Domains 页面为准。本轮文档整理没有重新检查线上部署状态。

## GitHub Pages

已有[部署工作流](../.github/workflows/deploy-pages.yml)。仓库 Settings → Pages 中将 Source 设为 GitHub Actions。工作流在推送 `main` 或手动触发时，使用 Node 24 安装依赖、运行测试、构建并发布 `dist`。

项目地址为 https://muleizhang.github.io/RDFZ2024Class7/ 。哈希形式的人物页无需服务端路由重写。发布状态以仓库 Actions 和 Pages 页面为准。

## 上传与常见问题

提交源码、已生成剧情、`public/assets`、依赖锁文件、构建配置及文档；不提交 `node_modules`、`dist`、本地存档、原始照片、私人配置或旧发布包。

- 本地地址打不开：检查开发服务是否仍在运行、端口是否一致。
- 线上图片缺失：确认提交了对应本地图片及资源映射，重新构建整站。
- 换站点后没有进度：使用旧站点导出、新站点导入。
- 文字立即全文：检查独立的“即时显示全文”开关；减少过场动画不会禁用打字。
- 页面仍是旧版：先确认部署的提交，再刷新页面。不要靠清空玩家存档修复部署问题。

## 音乐与音量

首次打开时，浏览器可能需要点击封面“开启音乐”或开始游戏后才允许播放。封面右上角可开关音乐；游戏设置可分别调节背景音乐、操作音效和真实翻页声，设为0即静音，偏好自动保留。同曲连续播放，跨场景换曲时淡入淡出；每次翻到不同日期响一次纸页声，读档不补播。音乐与翻页声的作者、源页、授权可从“关于七班日志”查看。原独立试听页 `/music-room/index.html` 保留，主游戏已采用用户确认的选曲。

### 背景图鉴

在游戏内打开“我的手帐 → 背景图鉴”，查看已经见过的风景及场景描述；可搜索、点开大图并切换已解锁图片。解锁记录随存档保存，新开局和读档会保留已有收藏。旧档继承原背景记录，新增加的背景在剧情中实际出现后解锁；全解锁作弊码也覆盖背景图鉴。
