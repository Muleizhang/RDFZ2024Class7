# 当前版本剧情内容缺失与设计问题审查

审查日期：2026-10-05。审查对象：当前全篇剧情文本，以及《全篇实装与出处》《制作进度》对内容完成情况的声明。

**结论：用户的感受成立。当前版本有完整的日历骨架和大量台词，但不能据此认定主体故事已充分完成。多处长篇被压成标题、梗名或一句结果；另有明确的人物归属、动作主体和故事因果错误。尤其十二钗、《数论》、秦敏然列传、邵聪观察日志、大哥的 Switch 故事，需要先纠错，再扩写。**

这份报告只审查内容。没有检查程序逻辑，没有启动或运行游戏，没有验证画面、音效、存档或分支可达性。读取 `src/data/chapter-part-*.ts` 仅为查阅其中已经写出的剧本文字，包括正文、选项和文字道具；不将制作文档的“已接入”“测试通过”当作叙事完成的证据。没有重新进行全卷扫描件的逐页图像校勘；原文依据是现有《全卷转写校勘》，明确存疑的字句不作为定错依据。

下文页码均为班史转写的原书页码；D 编号沿用现有剧情日历。节点链接用于直接定位当前台词，便于下一轮修改。连续节点范围写在正文中，链接定位其中一个起点。

## 一、先区分四种问题

| 类别 | 判定标准 | 当前例子 |
|---|---|---|
| 未收录 | 已安排或值得保留的素材，在全篇正文及文字道具中没有找到对应事件 | 刘树苡买书未读、喷气背包大雁作文；聪惠同饮奶茶及与尼德兰的联系 |
| 只提到，未演出 | 有标题、名词或结果，但玩家不知道发生了什么 | 文明礼仪奖、能礼、按压灭火法、备用考场 |
| 链条残缺 | 保留了局部对白，但删掉起因、转折或后果，使笑点或关系不成立 | 十二钗的“128字”、大哥从思维迟到思维驰、戴向阳46分作文 |
| 改错 | 实际写出的内容与明确原文相冲突 | 珈乐生日变黄艺博生日；朱老师拿可乐变徐子涵拿可乐；秦的笔袋变惠的笔袋 |

**不以全文照搬为目标。** 本纪、世家、列传不必成为游戏唯一主线，也不需要逐句复现；但选中的故事应让玩家经历其核心过程。能够主动舍去重复段落，不等于可以把每件事都缩成一句“有过这件事”。

当前新增章节文本共 2077 个节点，其中 `line` 1508 个、`scene` 346 个、角色切换提示 130 个、选择 33 个、日期 59 个、结尾 1 个；这些数字不含另存的开场样章。这里统计的是静态文本记录，**不是有效剧情数量或实际游玩长度**。同一句“把这一页收好，下一页还有新的课与新的声音。”出现 59 次；署名“班史原载”的摘录有 136 条。《镜中花》戏中戏相关记录有 348 条。可见标题、过渡、摘录与长篇原稿录入会显著抬高总数，不能替代逐事件验收。

## 二、十二钗：缺失最明显，也有两处严重改错

### 2.1 当前到底写了什么

D24 的核心内容是：黄艺博说“我来讲我的故事”；到曹雪芹故居；旁白式对白说“十二钗的命名也被拿出来讨论”；黄艺博说聊天有一百二十八字；张鹤闻提醒这是一面之辞。之后转到泡面、付款和李悦琳身份揭晓。见 [D24-0007](../src/data/chapter-part-03.ts:2447)、[D24-0010](../src/data/chapter-part-03.ts:2508)。

### 2.3 两个必须先改的事实错误

1. **“李悦琳其实是我”误写。** [D24-0019](../src/data/chapter-part-03.ts:2690) 将这句交给史绍恺。原文只说史绍恺把真相告诉黄艺博，设号一事发生在沛、冯君阳等人的聚会后。不能由“告知”推成“本人扮演”。
2. **生日主人和劝阻地点误写。** [D53-0015](../src/data/chapter-part-10.ts:1062) 写黄艺博说“明天我生日，想出去”，随后旁白写“校门前的劝返”。[原文第198页](/home/muleizh/Documents/ClassHistory/人大附中2024届7班班史_全卷转写校勘.md:6307) 明确是**珈乐生日、食堂门外**；李沛霖担心他前往庆生造成麻烦，拍摄安排与此交织。现在的“自己的生日没过完”改变了黄的动机，也改变了沛为何阻拦。

### 2.4 对前期计划的反省

此前《长篇素材取舍与防遗漏核对》把“追求史中的逐人细目与重复性化言辞”归为舍取；这一取舍范围写得过宽，是目前被过度压缩的上游原因之一，不能把问题全部归给后续实现。见 [《长篇素材取舍与防遗漏核对》](长篇素材取舍与防遗漏核对.md:83)。

但同一计划仍明确要求 D24 **展开** 自述、128字、听众反应和命名。现版本连这条主干也未完成。建议重新定义为：**保留几段有不同转折的代表故事，以及它们引发的后来后果；舍去重复细目，不舍去故事本身。** 不必为了丰富内容而逐人罗列，更不需要额外制造恋爱支线。

## 六、《镜中花》：主要问题是文本转成演出的质量

**本次未发现可以把《镜中花》整体归为“只有一句话”的依据。** 当前三个部分保留了从铁路事故、查账、黄义薄回忆、钢材公司、金跃山与嘉然、秦镇长与刘树颐互相揭示到结尾的长链条，正文量明显多于许多纪传。原稿编号跳过场景十一，不应据此认定漏写了一场。

但“原稿放进文本”与“视觉小说演出完成”仍有距离：

1. **校勘注混入角色台词。** [D52-0048](../src/data/chapter-part-09.ts:2546)—0049让代向阳在说“钢材最多几百万”后直接讲“以下为《镜中花》虚构剧本”“演员与角色严格按上方演职人员表对应”“原稿没有场景十一”。这不属于电影内对白，应移到幕后资料或进入戏中戏时的说明。
2. **断句与署名错误。** D52-0092—0093把“不得不承认现实”拆出新说话人“认现实”。黄义薄在档案室的独白也有多段挂在“场记”下（D53-0072—0076）。不论采用内心独白还是旁白，都应明确是黄的思考，不是拍摄记录者的想法。
3. **舞台说明未消化。** D55-0017—0020用刘树颐署名连续输出长串翻柜动作，D53-0118还留“做动作的时候别把脖子扭伤了”。动作信息本身有价值，但演员安全/拍摄提示与人物说话需在剧本层分开。
4. **句子被截成残片。** D53-0115—0117把一串动作拆成最后单独一个“）”；它贡献了节点，却没有独立阅读价值。这是文本编排问题，无须运行即可判定。
5. **幕后故事有更大压缩空间问题。** 电影正片保留长段原稿，现实里拍电影的同学却多是“有过笑场”“有过借场地”两句。可以保留电影篇幅，但优先让约拍冲突、机位互拍、花期变化、医务室笑场各有完整回合。尤其先修正珈乐生日，不要再把错误排期当成既定情节。
6. **对话选择没有进入电影关键谈话。** 现有戏中戏文本中未见选择节点；D52开场选择仍是“分清角色/现实金额”。若要强化既定“对话是核心”的形式，可以在追问、应答上给几处不改最终真相的选择，不需要变成调查小游戏，也不必每一场都设题。

## 七、贯穿全篇的设计问题

### 7.1 编剧和校勘约束被当成同学的性格

以下是实际玩家文本，不是仅留在后台的制作备注：

| 定位 | 当前文字 | 影响 |
|---|---|---|
| D27-0011 | “给老师看这个视频，不是让玩家来打一局。” | 人物在讨论游戏制作需求，而非当时同学之间的事情 |
| D25-0023 | “这页改订为十一月十一日，不能把补写落款当事件日。” | 校勘结论直接打断老师一天的故事 |
| D38-0015 | “镜头停在腰以上，只演交接与窘迫。” | 导演指令替代人物行动 |
| D41-0052 | “名字仍是戚洪硕，纸上仍是‘咸’，两个层次别互改。” | 明明刚完成改班牌的笑话，又回到数据校对 |
| D42-0020 | “两场忘麦可以呼应，日期不能合成一场。” | 同学忽然成了改编审稿人 |
| D57-0013 | “未来的快乐可以期待，不能冒充今天已经发生。” | 对回望日期的说明压过重逢情绪 |

真实性分层、日期不确定、戏中角色不等于演员，这些要求应继续遵守。但通常用**场景标题、回忆标识、资料注释**即可，不必让全班反复口头执行。现在许多人都用“不能当成……”“不要把……写成……”说话，原本的个性被同一种审稿语气覆盖。

### 7.2 “成功选择”变成如何正确编班史

用户要求的是：扮演当时重要的同学，选择不同说法，有些能接上原载事件，有些产生一句失败结局后重选。当前大量选项却是“记录事实”“不要编造成绩”“不把戏称当履历”，玩家更像资料审核员。

例如：

- D44失败项是“把十八天只学两天写成十八天每天都学得很好”，不是面对战老师时可能说出的回答。
- D46失败项是“宣称读懂可乐暗号就等于已经考到一百三十”，与当前交流缺少自然联系。
- D51让玩家选择“两轮都写”或删第一轮，作用是考忠实记录，不是参与竞速前后对话。
- D58失败项“宣布全班已经拿到尚未公布的成绩”，明显是给正确性检查准备的反例，角色没有这样说的动机。

**问题不在失败项容易识别，而在它不属于这个场景。** 同样允许多条成功路线，可以设计成打趣回应、认真解释、顺着对方问、先承认再补充等不同说法。每条成功应带来至少一点不同的现场回应，再回到同一事实结果。无需增加战斗、操作小游戏、复杂数值或另写大批架空结局。

### 7.3 成功选项常只被人物原样读出来

D36-0029—0030说“逗他一句，再把讲题的认真也留下”“记录事实，让他的反驳也有位置”；D46-0037—0038说“听着这个解释，再把答疑建议落到题上”“不猜定老师心意，也接受同学的安慰”。这些是写作意图，不是已完成对白。

应该把“逗他一句”真正写成惠子宁会说的一句调侃，再让邵聪回应。否则看似有分支，实际读到的是一份待扩写指令。

### 7.4 场景切得细，事件反而没演开

346个场景提示不等于346场完整戏。文明礼仪奖标题后只有一条泛泛评价；“期末之后”后直接转改班牌；杭州每换景点就再起标题，留给同学的实际问答很少。

建议把同一事件的起因、升级和结果放在连续可读的场景里。换背景是服务故事，不应成为完成度指标。此处只评价剧本文字的切分，未评价现有图片和实际切换效果。

### 7.5 多人物轮换退化成“轮流说总结”

许多切换句都是“这一段，由某某接着记”，随后当事人说一条抽象评价，再切走。D20在温雪异地片段让旁听者做“怎样回应时间错开”的决定；D49扮演徐子涵时却可选“鼓励他说明情况”，代词又站到外部。

轮换角色应改变玩家此时知道什么、在意什么、能向谁说话。可继续复用立绘，但不能把人物只作为轮流读史料的署名。一个关键事件通常先稳定在一位主要当事人，确有视角变化收益再切换。

### 7.6 统一收尾、励志拔高和原载追加造成节奏重复

59次相同的“把这一页收好……”足以使每日末尾失去区别。许多原本以尴尬、争辩或胡闹收束的事件又被加上“认真学习”“记清事实”的统一结论，甚至改变了《数论》、助跑、备用考场的原味。

翻日期动画已经承担结束一天的功能，文字可以停在当天最后一句有特点的回应。感动和成长可以来自老师的劳累、异地留言、实际练习进步，不需要把每个笑话都加工成教育总结。

对于“班史原载”摘录，先决定是演出还是资料阅读：前面已演过的同一事件，不必结尾再原样说明一次；新事件则挑关键问答接入人物，而不是连续交给“班史原载”这个统一说话人。原稿残句和疑读也不能因被整段复制就视为完成对白。

## 九、建议修订顺序与内容验收方式

### 第一轮：纠正已经讲错的故事

先处理十二钗生日、李悦琳、《数论》三组错误、秦的笔袋、邵聪观察日志、Switch、杭州角色归属、按压灭火误读、《镜中花》误署名与注释混入。它们会让继续补写沿错误关系扩展，不能只靠结尾加一句“以原文为准”。

### 第二轮：补回最值得演、目前损失最大的故事

推荐顺序：

1. 黄艺博植物园自述与128字、李悦琳揭晓、珈乐生日门前事件及余波。分散回忆可以，但每一段内部要成立。
2. 刘树苡手机赌约、文学/作文与画伞；戴向阳46分作文、办公室、备用考场；秦敏然失职与退款。
3. 满者礼仪奖、崔老师印象变化、套圈助跑；大哥Switch后的主动学习与期末回升。
4. 聪惠同桌互动及尼德兰缘起、温雪经戴杨洁探问与朋友圈误读；诸师至少各补一段能显出相处方式的现场。
5. 能者演讲、智者公开课白板、戚氏帮忙，以及火炉火等篇幅不长但能完整演出的日常。

不建议先为这些条目补一批新背景图，或先增加更多日期。许多缺口完全可以在现有教室、走廊、食堂、办公室和聊天框内补足。先写成能独立读懂的戏，再判断是否真的需要新背景。

### 第三轮：去掉制作说明口吻，重写选择与衔接

在事实和主体补齐后，集中清理“不能混淆”“别写成”“不是让玩家”等话；将必要说明移到不打断人物的地方。把选项改为当事人的具体说法，写出对方回应；删除重复原载与统一每日总结。避免边补故事边重复增加同类说明。

### 每个重点事件都用同一张验收卡

| 检查项 | 通过标准 |
|---|---|
| 出处与边界 | 能定位原书页；说明原载、自述、同学戏写、合理补白与未定信息，不把这张卡读进剧情 |
| 参与者 | 谁发起、谁回应、动作属于谁清楚；补白不替换亲历者、受影响者和决定结果的人 |
| 起因 | 不熟悉班史的玩家也知道为什么发生这件事，而非只看到一个梗名 |
| 过程 | 玩家见到至少一次关键问答、动作或误会升级；不以“他讲了五分钟”“众人大笑”代替应当演出的内容 |
| 结果与后续 | 保留原文的结果、命名由来及重要后果；分散在不同日时有必要的前情提示与回扣 |
| 选择 | 当前扮演的人确实可能这样说；成功回应有差别，结果仍符合记载；一句失败后可回选，不强制重读 |
| 人物声音 | 将署名遮住后，仍能从说法、关注点或动作看出性格差别，而非全员用相同审稿口吻 |
| 取舍 | 被舍去的内容有具体理由；不得把“计划舍去”“资料里有”“标题里写了”混作已经演出 |

**下一版的内容目标是让已选故事讲得成立、讲得有趣、人物关系讲得准确，而不是机械把每篇全文塞入，也不是继续用节点总数证明完整。** 现有日历、较完整的尼德兰/劝学/咸物论、若干日常短笑话和电影主体都可以沿用；重点修复以上事实错误和叙事缺口。
