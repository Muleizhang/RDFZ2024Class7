# 人物立绘接入

已将 `character-art/class-v2-galgame` 的52人、104张图片复制到游戏本地资源，保留原文件与旧共用图。现有剧情中52个角色ID使用个人图（含8个电影角色）；未出场人物的图片也在资源层登记，后续按姓名接入。老师等尚无个人图的角色仍使用原图。

服装按当前章节的现实日期：

- 2023年9月1日至2024年2月26日：秋季学期，长袖。
- 2024年2月27日起：春季学期，短袖。
- 暑假开场至8月：短袖。

回忆及电影沿用当前章节服装，不解析自由文本中的时间或虚构年份。对白、玩家切换过场、人物资料页使用同一映射。服装由日期计算，不修改存档格式；读取旧档会自动显示对应衣服。

`src/portraits.ts` 保留独立角色ID，电影使用角色的 `actor` 字段查演员，石杨按原书确认对应石杨子然。郑导已依用户最新确认合并到郑泽一，使用郑泽一立绘；九班徐子瀚不等于徐子涵。

维护方式：修改素材清单后运行 `node scripts/sync-portraits.mjs`，再构建。剧情生成器不覆盖独立的立绘资源表。运行时只需 `public/assets/portraits`，不依赖美术预览服务器、人脸照片或原素材目录。

本轮验证：17项自动检查通过，TypeScript及生产构建通过。浏览器实际检查1月11日唐朝长袖对白与过场，2月29日徐子涵短袖过场及390×844手机凌艺坤对白；人物资料中程洛怡和八个电影演员映射正确，无已加载失败图片，验收控制台无error。4173正式预览已加载新版本；未重打旧剧情整改ZIP。
