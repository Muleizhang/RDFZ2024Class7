# 七班日志

这是一本可以翻着玩的班史。

《七班日志》改编自人大附中2024届七班的班史。故事从2023年7月16日、徐启元的《入境 · 入静 · 劲》与序开始，沿着高三的日历，走到毕业与再会。

你会轮换成为不同同学，在课堂、课间、办公室和饭桌上接话、打趣、作出选择。迁楼、答疑、吃面、杭州游学，以及同学们拍摄的《镜中花》，和本纪、世家、列传中的往事一起穿插在日常里。老师与同学的认真、胡闹和误会，都留在这些书页中。

游戏以紫橙配色、纸张手帐和漫画切片呈现校园生活，配有人物立绘、日期翻页与课表。选择不同的说法，会得到不同回应；写岔了，也能回到刚才的选择再试一次。

这是以班史为依据的日常喜剧视觉小说。原载事件与结果构成故事基础，部分对白、内心活动和衔接为改编补写；回忆、同学的虚构作品与电影故事各有自己的阅读层次。
